# AnalystBench 前端功能说明

第一阶段前端以完成开放式分析报告 Benchmark 闭环为目标，不追求复杂的 Agent 可观测能力。

## 1. 数据集页面

用户可以：

- 创建数据集
- 添加问题材料
- 填写或上传人工标准答案
- 上传多个 Agent 版本的分析报告
- 查看 Case 数量和完成状态

单条 Case 主要展示：

- 问题描述
- 领域类型与标签
- 附件
- 人工标准答案
- Candidate 报告列表
- Eval Spec 状态

## 2. Eval Spec 编辑页面

页面左侧展示人工标准答案，右侧展示自动生成的评分标准。

用户可以编辑：

- Claim 内容
- Claim 类型
- 是否为核心项
- 权重
- 因果关系
- 已知错误结论
- 通过阈值

用户确认后生成固定版本的 Eval Spec。

## 3. Benchmark 运行页面

用户选择：

- 数据集版本
- Candidate 版本
- Eval Spec 版本
- Judge 模型
- 评分策略

然后启动批量评分。

## 4. 单 Case 结果页面

展示每个 Gold Claim 的匹配结果：

| 标准结论 | Agent 对应原文 | 关系 | 得分 | 说明 |
|---|---|---|---:|---|
| 根因结论 | 候选报告原文 | match / partial / missing / contradiction | 分值 | Judge 解释 |

同时展示：

- 总分
- 核心结论得分
- 关键结论覆盖率
- 因果关系得分
- 遗漏项
- 冲突结论
- Agent 报告原文定位

## 5. Benchmark 对比页面

支持对比两个 Candidate 版本：

- 总分变化
- 各维度变化
- 提升 Case
- 退化 Case
- 新增错误结论
- 根因命中率变化

第一版前端重点是解释评分结果，而不是展示复杂图表。
